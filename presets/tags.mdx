title: Tags
---

Tags are a powerful feature that allows you to label and categorize your preset prompts efficiently. By assigning tags to prompts, you can easily manage and retrieve them based on specific contexts or environments. This ensures that the right prompts are used in the right scenarios, streamlining your workflow.

## Creating Tags

### Step 1: Navigate to the Tags Section

To create a new tag, start by navigating to the Tags section of Murnitur. This is usually found under the settings tab.

<img style={{ borderRadius: "0.5rem" }} src="/images/tags_overview.png" />

### Step 2: Create a New Tag

1. Click on the "Create Tag" button.
2. Enter a descriptive name for the tag that reflects its purpose.
3. Optionally, add a color to the tag for easier identification.
4. Click "Create" to create the tag.

<img style={{ borderRadius: "0.5rem" }} src="/images/create_tag.png" />

## Using Tags

Once you have created your tags, you can start using them to label your preset prompts.

### Step 1: Tag Prompt

This can be done when creating a new prompt template or prompt version.

<img style={{ borderRadius: "0.5rem" }} src="/images/preset_add.png" />

### Step 2: Assign Tags to the Prompt

1. In the prompt's settings, locate the "Tags" field.
2. Start typing the name of the tag you want to assign, and select it from the dropdown list.
3. You can assign multiple tags to a single prompt if needed.
4. Click "Create Preset" to apply the tags to the prompt.

<img style={{ borderRadius: "0.5rem" }} src="/images/preset-single.png" />

## Conclusion

Tags are essential for managing and organizing your preset prompts effectively. By using tags, you can ensure that the correct prompts are deployed in the right contexts, leading to a more efficient and streamlined workflow.
